# CC Session Outbox — AmbientPanel: bigger sample + a real bug found along the way

**Date:** 2026-08-03

---

## What was asked

Continuing the "bigger sample size" thread from FieldIdentity into the
app's real main section: the AMBIENT card (top of the deployed site,
`AmbientPanel`), pointed to directly via screenshots of the live
`field-playground.jeffunglesbee.workers.dev` deployment.

---

## What was found

Read `AmbientPanel/index.jsx` and `src/data/relay.js`'s `fetchAmbient`
directly rather than assuming: the entire top section (star rating,
"sport of the week," editorial claim, quality-alert count, streak
board) is generated by ONE real per-date endpoint,
`/analytics/newspaper/{date}` — unlike `DramaLeaderboard`/
`HallOfSurprises`, there's no server-side `limit` param to widen. The
only genuine way to give this content a bigger sample is calling that
same real endpoint across a real date range.

Validated before building (`scripts/probe-ambient-multiday.mjs`, CI-as-
proxy): 10/10 real recent dates resolved, 10/10 distinct real editorial
claims, 7/10 distinct star scores — genuine day-to-day variation, not a
cached repeat.

**A real, currently-live bug surfaced by that same probe:** `sport_of_
week` rendered as the literal text `[object Object]` on 2 of the 10
real dates checked — including **today** (2026-08-03), the same date in
the user's screenshot. A follow-up probe
(`scripts/probe-sport-of-week-shape.mjs`) dumped the real raw shape:
`sport_of_week` is an object (`{winner, dramaTotal, gamesPlayed,
runnerUp, runnerUpDrama, summary, allSports[]}`), not the plain string
`SportOfWeekBanner` assumed. It's genuinely `null` on quiet days (already
correctly handled by the existing `<Show when={props.sport}>` gate) —
the bug was purely rendering the object instead of its real `summary`
field on the days it's populated.

---

## What was built

- **Fix:** `AmbientPanel`'s `SportOfWeekBanner` now renders
  `props.sport.summary` (the real, ready-made human-readable one-liner,
  e.g. "MLB (141/171 high-quality) edged WNBA (19/19).") instead of the
  raw object.
- **`src/data/relay.js`**: new `ambientWeek` resource — calls the same
  real `fetchAmbient` across a real 10-day window ending at
  `currentDate`, via `Promise.allSettled`. Each day is tagged
  `{ ok: true, data }` or `{ ok: false, error }` — a partial outage
  degrades to specific unavailable days, not a silently misleading
  empty result (the same fix class already applied to
  `VenueGeocodeRace`/`weather.js`).
- **`src/components/AmbientWeek/`**: new component, wired into the
  Journalism tab next to `BriefArchive`. Shows the real per-day star
  rating and editorial claim across the last 10 real days, a resolved-
  count summary, and the real best night by star score.

## Verified

- `npm run build` — clean (186 modules).
- All three automated guards (`check-resource-safety.mjs`,
  `check-unread-memos.mjs`, `check-localstorage-guards.mjs`) — clean;

- Local browser verification (Playwright, realistic mocked data
